Yokaii Player

Плеер для аниме, который не мешает смотреть

Открытый HTML5-плеер с сайта Yokaii. Без фреймворков и сборки: один ES-модуль и один CSS-файл.

На телефоне двойной тап по краю кадра перематывает, по центру — пауза. Пульт телевизора и медиакнопки гарнитуры тоже работают.

События плеера

    Их слушает страница: сохранить прогресс, включить следующую серию, синхронизировать совместный просмотр.
